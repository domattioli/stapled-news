Pipeline

How It Works

The pipeline streams articles from remote ISOT CSVs using resumable HTTP Range requests, avoiding full downloads. Claims (atomic actor-action-object units) are extracted per article and grouped by event (same headlines). Syndication clustering via simhash collapses near-duplicate copies into single votes. An online EM algorithm then iteratively estimates outlet consensus agreement and systematic omission/sensationalism by alternating between inferring event labels (E-step) and updating outlet reliability parameters (M-step), converging to a Dawid-Skene-style consensus model.

What this measures. The model estimates consensus, not objective truth — it identifies where outlets agree and diverge across reported events. These estimates reflect shared ground, not factual accuracy.
