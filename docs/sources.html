Data & Method

Three source corpora provide natural variation in outlet majority structure. Streaming EM pipeline: HTTP Range resumption → claim extraction → event clustering → simhash dedup → online expectation-maximization (E-step infers consensus, M-step updates outlet sensitivity per Dawid-Skene).

Pipeline

How It Works

Remote ISOT CSVs are fetched via resumable HTTP Range requests — no full download. Claims (actor-action-object triples) are extracted per article and grouped into events (same-headline clusters). Simhash deduplication collapses near-duplicate articles into fractional votes, isolating the wire-source from repetition-driven distortion. Online EM then alternates: E-step infers the true consensus label for each event given current outlet reliability estimates; M-step updates outlet sensitivity (and omission bias) to match the inferred labels. Convergence follows the Dawid-Skene framework.

What this measures. Online EM estimates consensus-agreement: the extent to which an outlet agrees with other outlets when both report the same event. This is a structural property of coverage, not a verdic t on truth. Consensus-agreement reflects popularity and co-coverage patterns, which can masquerade as corroboration when fabricated stories cluster.

Coverage Dominance: Synthetic Sources Outnumber Reuters 6:1

ISOT: 42,681 articles. Reuters (blue, real outlet) publishes ~6,000 articles; six synthetic sources publish ~37,000. This imbalance creates the condition for majority-capture: the model must assume the majority is truthful, so it ranks the fabricated sources higher.

Article Word Count Distribution (20k-sample)

Most articles cluster 400–1,200 words. Mean 752 words, median 700. Short wire-service reports and full feature articles both present.

Headline Length Distribution (20k-sample)

Most headlines cluster 40–100 characters. Synthetic sources use slightly shorter headlines, limiting claim granularity.

Claim Verb Distribution (top 12)

Actor-action predicates from claim extraction. Common verbs: says, reports, claims, announces, accuses, confirms. Negation ("no claims that…") carries no factuality signal — ~3% of UCI headlines.

Multi-outlet Event Rarity: Most Stories Are Singletons

ISOT: ~13k distinct events; ~10k appear in one outlet only. Only ~2.9k events are reported by 2+ outlets — these drive consensus inference. Log scale reveals the long tail of rare events covered by 3+ outlets.

Syndication Clusters: 73% of Articles Are Republished Copies

Simhash clustering: ~2,800 clusters detected. 73% of 42,681 articles are duplicates (size ≥2); largest cluster is ~450 copies of one wire story. Log scale. Dedup voting treats each cluster as a single vote, eliminating manufactured majorities from syndication.
